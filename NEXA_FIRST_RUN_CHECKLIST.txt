NexaShareControl 1.4.0 - FIRST RUN CHECKLIST

OPEN / STARTUP
[ ] NexaShareControl opens normally from Desktop/Start Menu.
[ ] Version badge shows 1.4.0.
[ ] Diagnostics shows startupComplete=true.
[ ] Diagnostics shows helper.available=true and helper.running=true.

UNIVERSAL WINDOW / PROGRAM DISCOVERY
[ ] Keep Unity open before starting this test.
[ ] OPEN APPLICATIONS contains Unity (or the actual Unity process name on the PC).
[ ] WINDOWS · Unity contains the open Unity editor/project window.
[ ] Search for "Unity" returns the Unity application/window.
[ ] ASSIGN APP assigns all open Unity windows.
[ ] ASSIGN TO SHARE assigns one individual Unity window.
[ ] ACTIVATE / RESTORE WINDOW brings that Windows window to the foreground.
[ ] Open another normal Windows app after NexaShareControl is already open and verify it appears automatically within a few seconds.

MONITORS / MULTI-SOURCE
[ ] SELECT MONITORS works.
[ ] SELECT ALL VISIBLE works up to the 16-source limit.
[ ] Assign Unity + a browser + Explorer + a monitor at the same time.
[ ] START SHARING SELECTED opens one preview per captured source.
[ ] DIRECT WINDOW or VISIBLE REGION is shown for each window source.
[ ] STOP SHARING stops all streams and preserves the assignment for another run.

NATIVE CONTROL
[ ] MOVE CURSOR TO CENTER works.
[ ] LEFT CLICK TEST works.
[ ] SCROLL TEST works.
[ ] TYPE TEST TEXT works in the focused application.
[ ] LIST WINDOWS returns the current Windows top-level window inventory.

SAFETY
[ ] Desktop Control is OFF after launch.
[ ] CTRL+SHIFT+F12 stops an active control session.
[ ] Closing and reopening the app does not create duplicate NexaShareControl processes.

If a test fails, run FULL DIAGNOSTICS and use:
%APPDATA%\NexaShareControl\logs\NexaShareControl.log


LOCAL VISION CONTROL 1.4.0
--------------------------
1. Install/run NexaShareControl 1.4.0.
2. Install Nexa Vision Relay 1.1.0 separately in D:\Nexa Vision Relay\.
3. In the Vision Relay popup click Pair control.
4. NexaShareControl must display a local approval dialog. Click Allow only if you initiated pairing.
5. Start Sharing Selected in NexaShareControl before any remote mouse/keyboard command.
6. Verify CTRL+SHIFT+F12 immediately disables Desktop Control.
7. Confirm the old Nexa ChatGPT Browser Relay 1.6.1 still works unchanged.
