NEXA SHARE CONTROL 1.1.0 - MANUAL DELIVERY

This ZIP is a FULL SOURCE REPLACEMENT for Nexa App Builder Pro Manual Delivery.

PURPOSE
- Keep NexaShareControl isolated from Nexa AI Local Bridge / Browser Relay.
- Build a Windows Electron app plus the native .NET 8 input helper.
- Add selectable simultaneous sharing for:
  * one or multiple monitors
  * one or multiple running applications
  * one or multiple individual Windows windows
  * any combination of the above

IMPORTANT BUILD ORDER
1. npm install / npm ci
2. npm run validate:delivery
3. npm run validate
4. npm run ui:smoke
5. npm run build:win

build:win MUST run build:native first. The Native Helper is copied to:
resources/bin/NexaShareControl.Native.exe
and electron-builder copies it to the installed app:
resources/bin/NexaShareControl.Native.exe

WINDOWS OUTPUTS
- NexaShareControl-Setup-1.1.0-x64.exe
- NexaShareControl-Portable-1.1.0-x64.exe
- NexaShareControl-1.1.0-x64.zip

SAFETY
Desktop control is OFF until START SHARING SELECTED is pressed.
Emergency Stop: CTRL + SHIFT + F12.
No keylogging and no UAC/security bypass are implemented.
