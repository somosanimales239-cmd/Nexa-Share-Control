NEXA SHARE CONTROL 1.2.0 - FULL MANUAL DELIVERY

USE THIS ZIP AS A FULL SOURCE DELIVERY FOR THE EXISTING Nexa-Share-Control PROJECT.
Do not merge it into Nexa AI Local Bridge or Browser Relay.

MAIN RELEASE CONTENT
- startup-resilient Electron application
- .NET 8 self-contained NexaShareControl.Native.exe build
- multi-monitor + multi-application + multi-window source picker
- simultaneous sharing for up to 16 selected capture sources
- independent preview and frame metadata per source
- monitor/window-targeted native pointer coordinates
- Developer Test Mode
- Builder-native validation matrix and Windows Delivery V3
- packaged EXE startup evidence
- installed EXE startup + Native Helper evidence
- NSIS install / Apps & Features / uninstall / reinstall verification

BUILD ORDER
GitHub Actions performs dependency setup. The package build command is:
  npm run build:native
  npm run validate
  electron-builder --win nsis portable zip --x64 --publish never
  npm run verify:artifacts

The Native Helper must exist before electron-builder runs at:
  resources/bin/NexaShareControl.Native.exe

Installed/unpacked location:
  resources/bin/NexaShareControl.Native.exe

EXPECTED OUTPUTS
- NexaShareControl-Setup-1.2.0-x64.exe
- NexaShareControl-Portable-1.2.0-x64.exe

FIRST WINDOWS TEST AFTER INSTALL
1. Confirm NexaShareControl window opens.
2. Run Full Diagnostics and confirm Native Helper running.
3. Refresh share sources.
4. Select one monitor and two different application windows.
5. Start Sharing Selected and confirm three independent previews.
6. Stop Sharing.
7. Developer Test Mode: Move Cursor, Left Click, Scroll, Type Test Text, List Windows, Activate Window.
8. Confirm CTRL+SHIFT+F12 stops an active session.

SOURCE VALIDATED != WINDOWS BUILD VERIFIED.
Only the successful GitHub Windows run can provide Windows Build Verified status.
