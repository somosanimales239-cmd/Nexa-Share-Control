USE THIS ZIP AS A FULL SOURCE DELIVERY FOR THE EXISTING Nexa-Share-Control PROJECT.

- startup-resilient Electron application
- .NET 8 self-contained NexaShareControl.Native.exe build
- Windows-native open-application/window inventory (EnumWindows is the source of truth)
- Unity and other normal visible Windows programs remain assignable even if Electron does not expose a direct window source

- VISIBLE REGION fallback using the monitor containing an otherwise unmatched native window

- multi-monitor + multi-application + multi-window sharing

- Developer Test Mode
- Builder-native validation matrix and Windows Delivery V3

- installed EXE startup + Native Helper evidence
- NSIS install / Apps & Features / uninstall / reinstall verification

BUILD ORDER
GitHub Actions performs dependency setup. The package build command is:
  npm run build:native
  npm run validate
  electron-builder --win nsis portable zip --x64 --publish never
  npm run verify:artifacts

The Native Helper must exist before electron-builder runs at:
  resources/bin/NexaShareControl.Native.exe

Installed/unpacked location:
  resources/bin/NexaShareControl.Native.exe

FIRST WINDOWS TEST AFTER INSTALL
1. Open Unity before NexaShareControl.
2. Confirm NexaShareControl opens and Native Helper is running.
3. Confirm OPEN APPLICATIONS shows Unity and the WINDOWS · Unity group shows the editor/project window.
4. Assign Unity, a browser, Explorer and one monitor simultaneously.
5. Start Sharing Selected and confirm independent previews.
6. Open another desktop program and verify it appears automatically after Stop/while idle.
7. Run Developer Test Mode: Move Cursor, Left Click, Scroll, Type Test Text, List Windows, Activate Window.
8. Confirm CTRL+SHIFT+F12 stops an active session.
