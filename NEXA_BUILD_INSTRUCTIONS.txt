NexaShareControl 1.0.1 - COMPLETE REPLACEMENT

PURPOSE OF THIS RELEASE
- Fixes installed application silently closing/not opening.
- Main window now opens BEFORE native helper/network initialization.
- Native helper, tray, transport, security, or hotkey failure can no longer close the whole application.
- Adds dedicated NexaShareControl Electron user-data isolation.
- Adds startup issue reporting in the application and Diagnostics.
- Does NOT modify or depend on Nexa AI Local Bridge, Nexa Local, Browser Relay, SFTP Publisher, or existing Unity projects.

MANUAL DELIVERY
1. Upload this ONE ZIP as a complete source replacement for Nexa Share Control.
2. Do not combine with 1.0.0 patches.
3. Apply staged files once.
4. Confirm application version 1.0.1.
5. Run Local build validation.
6. Push to GitHub & Build.
7. Install NexaShareControl Setup 1.0.1 over the previous version.

EXPECTED STARTUP
- NexaShareControl window must open even if the native helper has a problem.
- If a background component fails, the application stays open and displays the exact issue.
- Diagnostics reports the helper path, user-data path, and startup issues.
